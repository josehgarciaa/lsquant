# LSQuant Python package

LSQuant computes spectral and transport properties using Chebyshev expansions.
This package provides the Python API, observable-word compiler and run-file CLI.

Install the Python package from the repository root with `pip install -e python/`.
The compiled `lsquant._core` extension must be built separately with CMake;
installing this package does not compile it. See the
[installation guide](https://josehgarciaa.github.io/lsquant/how-to/install/).

The package's `lsquant/README.md` describes the Python interface in more detail.
